# BarangayPulse – Complaint Pattern Analysis & Priority Monitoring

A Streamlit dashboard prototype for exploring barangay complaint patterns, monitoring complaint priority and status, and demonstrating machine-learning-based priority classification.

## Features
- KPI overview and complaint trend analytics
- Category, zone, status, and priority visualizations
- Interactive filters and searchable complaint register
- Random Forest priority classification with held-out test metrics
- CSV download for filtered records

## Run locally
```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

The included dataset is synthetic demonstration data and should not be treated as actual barangay records or operational recommendations.
